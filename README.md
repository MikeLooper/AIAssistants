# AI Assistants

AI Assistants to accomplish a multitude of tasks.

## Notable AI Assistants

`compliance-reviewer_agent-only` - An agent for determining how well application source code is complying with standards and best-practices.  This assistant uses only agents, skills, and related AI tooling.
- [README](compliance-reviewer_agent-only/README.md)

`compliance-reviewer_agent-plus-python` - An agent for determining how well application source code is complying with standards and best-practices.  This assistant uses agents, skills, and related AI tooling along with some Python scripting to cut back on some of the credits spend.
- [README](compliance-reviewer_agent-plus-python/README.md)

`job-search-agent` - A Job Search tool will read job boards and present a display of how well listed jobs match some specified search criteria.
- [README](job-search-agent/README.md)

`mcp-server-usage-demo` - A demo of how to use a MCP server in an agent.
- [README](mcp-server-usage-demo/README.md)

`unit-test-logic-agent` - A prompt-driven AI agent that evaluates unit tests based on code logic and element coverage, not line coverage.
- [README](unit-test-logic-agent/README.md)
