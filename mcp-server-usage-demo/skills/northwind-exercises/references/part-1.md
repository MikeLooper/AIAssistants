# Northwind Exercises — Part 1

1. Create a report that shows all category names with their descriptions from the Categories table.
2. Create a report that shows the contact name, customer id, and company name of all Customers in London
3. Create a report that shows a list of company names and contact names of all the Owners from the Customer table from Mexico, Sweden and Germany.
4. Create a report that shows the count of the number of discontinued products in the Products table.
5. Create a report that shows all the company names, city, country and postal code from the Suppliers table with the word 'rue' in their address. The list should be ordered alphabetically by company name.
6. Create a report that shows the product id and the total quantities ordered for each product id in the Order Details table.
7. Create a report that shows all product names from the Products table that are condiments.
8. Create a report that shows a list of customer names who have no orders in the Orders table.
9. Add a shipper named 'Amazon' to the Shippers table.
