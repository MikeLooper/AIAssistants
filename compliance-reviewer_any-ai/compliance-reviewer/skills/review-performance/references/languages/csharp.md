# Language Signals — C#/.NET (Performance)

Local lookup table, not a standard. Use it to classify code and configuration for PERF-01 … PERF-08; cite the AZPE elements, never this file. If a library isn't listed and you can't classify it, add `localized-standard-gap: unrecognized library <name>` to `notes`.

| Area | Pass signals | Anti-patterns / fail signals |
|---|---|---|
| Concurrency model (PERF-02, SKILL.md step 2) | ASP.NET Core (controllers, minimal APIs, Razor Pages, Blazor Server, SignalR), Worker Service / `BackgroundService`, Azure Functions isolated worker: **async-first** | — |
| Caching (PERF-01) | `IMemoryCache` with `AbsoluteExpirationRelativeToNow` / `SlidingExpiration` and `SizeLimit` + `SetSize`; `IDistributedCache` (`AddStackExchangeRedisCache`) with `DistributedCacheEntryOptions`; `HybridCache` (.NET 9+); output caching (`AddOutputCache`) and `[ResponseCache]` for pages and static assets; `StringIncrement`, transactions or Lua scripts for shared counters; `IBatch` / multi-key `StringGet(RedisKey[])` | `static Dictionary` / `ConcurrentDictionary` used as a cache with no eviction; `IMemoryCache.Set` with no expiration for mutable data; `IMemoryCache` holding shared mutable data in a multi-instance deployment; separate `StringGet` + `StringSet` for counters; one `StringGetAsync` per key inside a loop |
| Non-blocking I/O (PERF-02) | `async`/`await` end to end; `ToListAsync`, `SaveChangesAsync`, `HttpClient.GetAsync`, `Stream.ReadAsync`; `Task.WhenAll` for independent calls; `SemaphoreSlim` or `Parallel.ForEachAsync` with `ParallelOptions.MaxDegreeOfParallelism` for fan-out | `.Result`, `.Wait()`, `.GetAwaiter().GetResult()` in request or handler code; sync EF Core (`ToList()`, `SaveChanges()`, `First()`) in controllers or handlers; `Task.Run(() => syncIo())` in ASP.NET Core; `async void` outside event handlers; `Thread.Sleep` in request paths; unbounded `Task.WhenAll(items.Select(...))` against a shared resource |
| Client reuse and pooling (PERF-03) | `IHttpClientFactory` (`AddHttpClient`, typed or named clients); static `HttpClient` with `SocketsHttpHandler.PooledConnectionLifetime`; `ServiceBusClient`, `CosmosClient`, `BlobServiceClient`, `ConnectionMultiplexer` registered as singletons; ADO.NET pooling (on by default) with `Max Pool Size` set; `AddDbContextPool`; `ObjectPool<T>` / `ArrayPool<T>` | `new HttpClient()` per call or in `using`; `ConnectionMultiplexer.Connect` per operation; new `CosmosClient` / `ServiceBusClient` per request; changing `DefaultRequestHeaders` per request; `Pooling=false` in connection strings; `SqlConnection` kept in a field across requests |
| N+1 and chatty I/O (PERF-04) | `Include` / `ThenInclude`, projection with `Select`, `AsSplitQuery`; `AddRange` + one `SaveChangesAsync`; `ExecuteUpdateAsync` / `ExecuteDeleteAsync` (EF Core 7+); `SqlBulkCopy`; `BufferedStream` / `StreamWriter` kept open for the loop | `UseLazyLoadingProxies` with navigation access in loops or serialization; a query or `FindAsync` inside `foreach`; `SaveChanges` inside a loop; `File.AppendAllText` per item in a loop |
| Hot-path code (PERF-05) | `StringBuilder`; `static readonly Regex` or `[GeneratedRegex]`; `ArrayPool<T>`, `Span<T>`; `HashSet` / `Dictionary` lookups; `[LoggerMessage]` | `+=` on strings in loops; `new Regex(...)` inside loops; `List.Contains` over large lists inside loops; reflection per iteration; `LogInformation` per item in large loops |
| Data retrieval (PERF-06) | `Select` projections; `AsNoTracking` for read-only queries; `Skip` / `Take` with a server-side maximum; `[Timestamp]` / `IsConcurrencyToken` / `IsRowVersion` | `AsEnumerable()` / `ToList()` before `Where` / `OrderBy` / `Sum`; returning a whole `DbSet`; `FromSqlRaw("SELECT * …")`; `UPDLOCK` / `HOLDLOCK` hints without need; `ILogger` sinks or queue tables writing to the business database |
| Offloading (PERF-07) | `BackgroundService` / `IHostedService` reading a `Channel<T>` or queue; Service Bus / Storage Queue processors; Hangfire / Quartz.NET; Functions queue triggers | `new Thread(...)`, fire-and-forget `Task.Run` or `ThreadPool.QueueUserWorkItem` started from a controller for heavy work; long CPU work inline in an action |
| Scale-out and serving (PERF-08) | `AddSession` over a distributed cache (Redis, SQL Server); `AddResponseCompression`; Kestrel `Protocols` including `Http2`; `UseStaticFiles` with `OnPrepareResponse` cache headers, or a CDN | `AddSession` over `AddDistributedMemoryCache` in a multi-instance deployment; per-user state in static fields shared across requests |
