# Language Signals — Python (Performance)

Local lookup table, not a standard. Use it to classify code and configuration for PERF-01 … PERF-08; cite the AZPE elements, never this file. If a library isn't listed and you can't classify it, add `localized-standard-gap: unrecognized library <name>` to `notes`.

| Area | Pass signals | Anti-patterns / fail signals |
|---|---|---|
| Concurrency model (PERF-02, SKILL.md step 2) | `async def` handlers in FastAPI, Starlette, aiohttp, Sanic, Django async views (under ASGI): **async-first**. Django / Flask under WSGI (gunicorn, uWSGI), FastAPI plain `def` endpoints, Celery tasks: **thread/process-per-request** | — |
| Caching (PERF-01) | `functools.lru_cache(maxsize=N)`, `cachetools.TTLCache` / `LRUCache`; Django `CACHES` with Redis / Memcached and `TIMEOUT`; Flask-Caching with `CACHE_DEFAULT_TIMEOUT`; redis-py `set(..., ex=)`; `cache.delete` on writes; redis-py `incr`, pipelines, `mget` | `functools.cache` / `lru_cache(maxsize=None)` on functions with unbounded inputs; module-level `dict` caches without eviction; Django `LocMemCache` holding shared mutable data with several processes or instances; `timeout=None` for mutable data; `get` then `set` for shared counters |
| Non-blocking I/O (PERF-02) | In `async def`: `httpx.AsyncClient`, `aiohttp`, `asyncpg`, SQLAlchemy async engine, `aiofiles`, `asyncio.gather` (with `asyncio.Semaphore` for fan-out); `run_in_threadpool` / `asyncio.to_thread` for unavoidable blocking libraries | `requests.*`, `time.sleep`, sync DB drivers (`psycopg2`, sync SQLAlchemy `Session`) or blocking file I/O inside `async def`; CPU-heavy work in `async def`; `asyncio.run` / `loop.run_until_complete` inside a running loop; unbounded `asyncio.gather` over input-sized lists |
| Client reuse and pooling (PERF-03) | One `requests.Session` / `httpx.Client` per process; `create_engine` once at module level with `pool_size` / `max_overflow`; Django `CONN_MAX_AGE` (+ `CONN_HEALTH_CHECKS`); `redis.ConnectionPool`; boto3 / Azure SDK clients created once (outside the serverless handler) | `create_engine` or `psycopg2.connect` per request; boto3 / Azure SDK client construction inside the handler on every invocation; a new `httpx.AsyncClient` / `aiohttp.ClientSession` per request; `poolclass=NullPool` in a long-running web app |
| N+1 and chatty I/O (PERF-04) | Django `select_related` / `prefetch_related`; SQLAlchemy `selectinload` / `joinedload`; `bulk_create` / `bulk_update`; `executemany`; one open file handle for the loop | accessing foreign keys or relationships in loops without eager loading; `session.query` / `Model.objects.get` inside loops; `.save()` per item in loops; `open(..., "a")` per item in a loop |
| Hot-path code (PERF-05) | `"".join(...)`; `re.compile` at module level; `set` / `dict` membership; comprehensions; lazy `%s` logging args | `+=` on strings in loops; `re.compile` / `re.match` with new patterns inside loops; `in` on large lists inside loops; `logger.info` per item in large loops |
| Data retrieval (PERF-06) | `.only()` / `.values()` / `.values_list()`; SQLAlchemy `load_only`; `.filter()` / `.aggregate()` / `.count()` in the DB; DRF `PAGE_SIZE` with a pagination class that sets `max_page_size`; optimistic version columns (SQLAlchemy `version_id_col`) | `list(Model.objects.all())` then filtering in Python; `len(queryset)` instead of `.count()`; unsliced `.all()` returned by list endpoints; `select_for_update()` on read paths; DB log handlers writing to the business database |
| Offloading (PERF-07) | Celery / RQ / Dramatiq / Arq workers; FastAPI / Starlette `BackgroundTasks` only for short, non-critical work; Celery beat for off-peak jobs | `threading.Thread` started in a request handler for heavy work; long CPU work inside request handlers; heavy work in `BackgroundTasks` |
| Scale-out and serving (PERF-08) | Django `SESSION_ENGINE` backed by a shared cache or DB, or signed-cookie sessions; Flask-Session with Redis; `GZipMiddleware`; WhiteNoise with cache headers, or a CDN | file-based or local-memory sessions with several instances |
